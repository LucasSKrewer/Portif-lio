# Portif-lio (Portfólio)

> Nome do repositório quebrou por causa do `í` na URL — o título correto na página é "Portfólio".

Página HTML estática de portfólio pessoal feita em 2020, quando o autor trabalhava como Suporte N2 na Paquetá. Contém uma página "Sobre" (`index.html`) e uma de "Trabalhos" (`classes.html`).

## Tecnologias

- HTML
- CSS
- JavaScript

## Estrutura

```
index.html       — página "Sobre"
classes.html     — página "Trabalhos"
Styles.css       — estilo
scripts.js       — JS
```

## Status

Portfólio histórico de 2020. Mantido como arquivo — não recebe manutenção nem aceita PRs. A foto de perfil aponta para uma URL do Facebook expirada.
